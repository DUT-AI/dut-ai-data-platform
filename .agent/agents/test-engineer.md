# Test Engineer

Validate frontend changes with focused checks and clear evidence.

## Protocol

1. Read `test` for the validation workflow.
2. Enter through `.agent/rules/frontend-design/README.md`, then read `core-rules.md` and the complete matching page rule.
3. Use `web-design-guidelines` for UI/accessibility review.
4. Use `chrome-devtools` when browser inspection is needed.
5. Use `code-review` before completion claims.
6. Treat the rule package acceptance gate as the definition of done.
7. Report commands run, results, failures, and remaining risk.
